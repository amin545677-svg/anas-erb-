نسخة تطويرية

نظام لإدارة المبيعات والمشتريات والعملاء والموردين والمخزون والديون والصندوق والتقارير، مع أدوات الاستيراد والنسخ الاحتياطي بحسب الوظائف المتاحة في هذه النسخة.

تُحفظ البيانات والإعدادات وفق آلية التخزين المفعّلة في التطبيق. احتفظ بنسخة احتياطية منتظمة من بياناتك.

السحابة والمزامنة والنسخ الاحتياطي
🔄
حالة حفظ البيانات: محفوظة محلياً ✅

احفظ نسخة من بياناتك لاسترجاعها بالكامل فوراً عند تغيير الهاتف أو فقدان جهاز العمل:

☁️ ربط Firebase — Anas ERP

تسجيل دخول آمن ومزامنة نسخة بيانات التطبيق. يجب إعداد قواعد Firestore الخاصة بمالك المشروع قبل الرفع أو الاسترجاع. لا تشارك كلمة المرور مع أحد.

مهم: هذا رابط عامل Firebase للنسخ الاحتياطي، ويجب أن يكون منفصلًا عن عامل الذكاء الاصطناعي. لا تستخدم رابط Gemini الحالي هنا ولا تستبدل كود عامل الذكاء الاصطناعي. انشر عامل Firebase جديدًا مستقلًا ثم ضع رابطه هنا.

سبب المشكلة والحل: تسجيل Google والربط السحابي يحتاجان إلى فتح التطبيق عبر رابط HTTPS منشور، وليس من الملف المحلي في التنزيلات.

إعداد Firebase موجود. يلزم نشر هذه النسخة على HTTPS والسماح بالنطاق في Firebase. لم يتم التحقق من الدخول أو صلاحيات السحابة بعد.

تنبيه: لا تستخدم قواعد تسمح للجميع بالقراءة والكتابة. إذا ظهرت رسالة صلاحيات، أوقف المزامنة وأرسلها لي؛ لا تفتح القاعدة للعامة.

تنبيه: رابط مشروع Supabase أو جدول Google Sheets وحده لا يكفي. يجب أن يكون الرابط واجهة API تستقبل POST بصيغة JSON وتعيد البيانات عند طلب GET. لا تضع كلمة مرور أو مفتاحًا سريًا هنا.

المزامنة غير مُختبرة. احفظ رابط API صالحًا ثم جرّب الإرسال أو الاسترجاع.
