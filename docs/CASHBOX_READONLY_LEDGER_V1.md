# دفتر الصندوق للقراءة فقط — V1

تعرض الشاشة الحركات المسجلة في `AppData.cashMovements` مع البحث والتصفية وإجمالي المقبوضات والمدفوعات وعدّ السجلات غير الصالحة.

## ضوابط السلامة
- العرض للقراءة فقط؛ لا ينشئ حركات ولا يغيّر الأرصدة أو السجل.
- تبقى السجلات غير الصالحة ظاهرة لأغراض التدقيق ولا تُحوّل إلى أصفار.
- لا يُستنتج رصيد افتتاحي أو إقفال يومي من بيانات ناقصة.
- القبض والصرف يمران حصراً عبر مسارات الترحيل المعتمدة.

## حدود الإصدار
هذا ليس دفتر أستاذ نقدياً كاملاً ولا ينفّذ إقفالاً يومياً. يتطلب الإقفال المستقبلي دفتر حركات موحداً بمعرفات مصدر ثابتة، وترحيلاً ذرياً قابلاً لإعادة المحاولة، وصلاحيات اعتماد، وقيود عكس تحفظ الأثر التاريخي.
