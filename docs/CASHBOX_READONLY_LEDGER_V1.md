# دفتر الصندوق للقراءة فقط — V1

## النطاق
تعرض الشاشة الحركات الموجودة فعلياً في `AppData.cashMovements`، مع البحث والتصفية وإجمالي المقبوضات والمدفوعات وعدّ السجلات غير الصالحة.

## ضمانات السلامة
- لا تنشئ الشاشة حركات مالية ولا تعدّل السجل أو الرصيد.
- لا تستنتج رصيداً افتتاحياً أو إقفالاً يومياً من بيانات ناقصة.
- تعرض السجلات غير الصالحة كاستثناءات تدقيق بدلاً من إسقاطها.
- تتم عمليات القبض والصرف عبر مسارات الترحيل المعتمدة فقط.

## حدود V1
هذا عرض تدقيقي للقراءة فقط، وليس دفتر أستاذ نقدياً كاملاً أو عملية إقفال يومية. يتطلب الإقفال مستقبلاً دفتر حركات موحداً بمعرفات مصدر ثابتة، وترحيلاً ذرياً قابلاً لإعادة المحاولة، وصلاحيات اعتماد، وقيود عكس بدلاً من تعديل التاريخ.
